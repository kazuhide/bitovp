# VOD入力タイムライン：境界スナップ

## 目的

V1/A1を別々に編集するとき、反対側のカット点へ端を合わせやすくする。既存の連結・差し替え・AV連動編集と固定尺度を保つ。

## 操作

- スナップは初期状態で有効。ズームの隣に磁石ボタンを置き、オン／オフを切り替える。常時説明文は増やさず、短いツールチップを付ける。
- 個別トラックの開始・終了ハンドルをドラッグすると、V1/A1の他クリップの開始・終了、シーケンス先頭・末尾、現在の再生位置へ吸着する。
- 動かしているクリップ自身は候補から除く。個別編集で動かない反対側のクリップは候補として残す。
- 目盛りをクリックして分割位置を決めるときも、クリップ境界へ吸着する。時間入力、範囲スライダー、キーボードのフレーム／ミリ秒調整は正確な指定を優先し、吸着させない。
- Alt／Optionを押している間は一時解除。ドラッグの途中に押したり離したりした場合も反映する。
- 吸着中だけ、両トラックを貫く破線と時刻を表示する。終了・キャンセル・外部文書変更時に消す。色だけに依存しない。

## 判定

吸着開始は画面上の8px以内、吸着を保つ範囲は12px以内とする。ズームからミリ秒へ変換し、吸着済み候補を少し長く保つことで境界付近の揺れを抑える。複数候補は最も近いもの、同距離なら早い時刻を選ぶ。

素材の実ストリーム尺、最小1ms、シーケンス範囲に収まる候補だけを使う。吸着した端は共通の整数msへ正確に合わせ、通常ドラッグの映像フレーム刻みは維持する。スナップ後も既存の編集検証とUndo/Redoを通す。

AV連動トリムは開始位置固定のリップル編集なので、今回はその操作の意味を変えない。クリップ本体のドラッグも既存の並べ替えを維持する。自由な時刻への移動や新しい重なり規則は追加しない。

## 検証

1. 純粋関数で候補除外、同距離、ズーム、吸着の維持／解除、無効な数値を確認する。
2. UIでA1→V1・V1→A1、左右端、範囲制約、Alt／Option、オン／オフ、キャンセル、Undo、キーボードの細かな調整を確認する。
3. Dockerの実ブラウザーでガイドを撮影し、スナップした時刻で分割・プレビューできることを確認する。既存の基本編集・AV差し替えも再検証する。
4. 型検査・ビルド・CIと、同じcmux内で並列表示するCodex Rescue／Agentチームの独立レビューを実施する。
