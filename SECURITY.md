# Reporting a vulnerability

Use [GitHub's private vulnerability reporting form](https://github.com/kazuhide/bitovp/security/advisories/new) to report a suspected security issue. Include the affected version, steps to reproduce it, and its impact.

Do not include API keys, passwords, cloud credentials, or customer data. Redact these values from configuration files and logs before sharing them.

For general bugs and feature requests, use [GitHub Issues](https://github.com/kazuhide/bitovp/issues).
