# Roadmap

Planned improvements to bitovp. Scope and timing may change after testing and
feedback.

- **Banding detection in quality control:** Show banding scores and affected
  time ranges, with configurable warning and failure thresholds.
- **GPU decoding and VMAF v1.0 processing:** Validate supported GPU paths against
  the CPU reference, preserve the selected model, and measure end-to-end speed
  and memory use.
- **Content Library clip editor:** Create highlight and vertical clips through
  range selection, preview, and adjustable cropping. Save edits and export new
  assets while preserving the originals.

Delivered changes are recorded in the [changelog](./CHANGELOG.md).
