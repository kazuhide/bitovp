# v1.0.0-rc フィードバック対応

## 目的と範囲

認証情報の入力とVODの初期設定を改善し、Bitmovinアカウントに保存した
エンコード設定をVOD/Liveの作成時に使えるようにする。リリースやタグは作成しない。

| 機能 | 責務 | 依存 |
| --- | --- | --- |
| credential-entry | 外部サービスの認証情報入力で保存・自動入力の抑止ヒントを指定 | なし |
| vod-ladder | Per-Titleへの切替と新規音声の初期値を修正 | なし |
| account-defaults | アカウント既定値の編集とウィザードでの選択時適用 | 既存のアカウントAPI |
| scene-overlay | VOD再生プレビューとライブラリで共通のAISA重ね表示を読みやすくする | 既存の再生画面 |

独立した機能は並列に実装し、統合後にテスト・ビルド・2系統のレビューを行う。

## 受入条件

- 外部サービスの秘密情報はネイティブのマスクと通常の編集操作を維持する。
  フォームと入力に保存・自動入力の抑止ヒントを付ける。
  ブラウザや拡張機能の判断による保存ダイアログの完全な抑止は保証しない。
- 標準から通常のPer-Titleへ切り替えた動画行の高さは空欄にする。
  既存のPer-Title行に入力した高さ、インポートや下書きの値は保持する。
  固定解像度を必要とするPer-Titleモードの制約は維持する。
- VODの新規音声はAAC、128,000 bps、48,000 Hz、CL_STEREOとする。
  保存済みプランや利用者が編集した音声は書き換えない。
- 設定のBitmovinアカウントでクラウドリージョンとエンコーダバージョンを選べる。
  バージョンはSTABLE、BETA、固定バージョンに対応し、既存の未知の値も保持する。
- VOD/Liveで利用者がアカウントを選ぶと、そのアカウントの既定値を設定する。
  既定値がない既存アカウントでは各ウィザードの初期値を使う。
  選択後の手動変更は保持し、データの再取得で上書きしない。
- 下書き復元・複製・テンプレート・JSONインポートは元の設定を保持する。
  フォームで別アカウントへ明示的に切り替えたときは切替先の既定値を適用する。
  フォームで表現できないエキスパートJSONでは、既存の契約どおりJSONの設定を優先し、
  アカウント選択は未指定のアカウントIDだけを補う。
- AISAの「シーン情報を重ねて表示」は、暗色・明色など各テーマで本文を読める配色にする。
  背景と文字を同じテーマの色の組み合わせで切り替え、半透明背景の不透明度は95%とする。
  明るい映像・暗い映像の両方に重ねたときの文字コントラストを検証する。
  VODジョブの再生プレビューとコンテンツライブラリに共通で適用する。

## 実装と検証

既存のReact、React Hook Form、Zod、RegionSelect/SelectNativeの構成に合わせ、
新しい依存関係やDBマイグレーションは追加しない。既定値は既存の
`BitmovinAccount.defaults`に保存する。テストは隣接するVitest/Testing Libraryに追加する。

```sh
rtk pnpm --filter @bitovp/web exec vitest run src/app/settings/bitmovin/bitmovin-form.test.tsx src/__tests__/wizard-account-defaults.test.tsx
rtk pnpm test
rtk pnpm check
rtk pnpm typecheck
rtk pnpm build
```

テスト・ビルド結果とレビューを確認し、PRをmainへマージする。
外部のBitmovinエンコード実行は行わない。
